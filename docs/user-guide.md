# 使用教程

手机截屏或导入截图 → 裁剪小地图 → 云端分析 → 手机合成语音并播报。

## 从仓库构建并安装

1. 安装 DevEco Studio 26.0.1.290，在 SDK Manager 安装 HarmonyOS SDK 26.0.1，使用 IDE 自带的构建工具。
2. 克隆或解压完整仓库，用 DevEco 打开含 `build-profile.json5` 的根目录，等待 Sync 完成；语音模型和原生库已随源码提供。
3. 手机开启开发者模式和 USB 调试，连接电脑并解锁，在手机上确认调试授权。
4. 打开 `File > Project Structure > Project > Signing Configs`，为 `default` 勾选 `Automatically generate signature`，登录华为开发者账号并点击 `Apply / OK`。
5. 建议进行独立调试，可选择“未关联注册应用”并自动签名；
6. 选择 `entry`、`default`、debug 和已连接的手机，点击顶部设备名右侧的 Run，完成构建、安装和启动。

签名后的 HAP 位于 `entry/build/default/outputs/default/entry-default-signed.hap`。
每位开发者使用自己的账号为目标手机生成签名，签名文件保存在本机。

## 配置并试用

1. 滑到配置页，填写云平台提供的 HTTPS 兼容接口 URL、API Key 和视觉模型 ID，默认模型为 `qwen3.6-flash`，配置会缓存存储。
2. 静态分析：回首页点击“导入系统截图”，选择一张横屏游戏截图。
3. 在配置页用“左移、右移、收窄、加宽”调整范围，让“实际发送的小地图”包含完整地图并避开队友头像。
4. 按头像边缘的红蓝环设置“我方英雄标记边框”，再回首页点击“分析这张截图并播报”。
5. 在配置页调整云端分析间隔和播报语速；分析间隔默认 10 秒，缩短间隔会增加云端调用。
6. 动态分析：首页点击圆形“开始”，允许通知与系统录屏，录屏范围选择“整个屏幕”，然后切到游戏并保持屏幕亮起。
7. 返回应用点击“停止”结束采集和播报。

## 遇到问题

- 签名文件缺失：连接手机，在签名页取消再重新勾选自动签名，点击 `Apply / OK` 后重新运行。
- 没有声音：先用配置页试听检查媒体音量，再用静态截图分析检查云端配置。
- 截图发黑或裁剪偏移：在配置页“采集检查”对照原始帧与小地图，重新授权录屏或调整选区。
- 识别误报：对照“实际发送的小地图”和分析帧时间，检查录屏红点是否进入选区。
